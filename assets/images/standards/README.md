# Standards logos

Monochrome versions of each standard's own logo, inlined on the home page in navy
(fills set to `currentColor`). Used to show which standards sbomify works in.

| File | Source |
| --- | --- |
| `cyclonedx.svg` | OWASP CycloneDX branding, `CycloneDX/cyclonedx.org-archived` `about/branding/cyclonedx-logo-black.svg` |
| `spdx.svg` | SPDX outreach assets, `spdx/outreach` `assets/SPDX_Logo/svg/SPDX logo black.svg` |
| `csaf.svg` | OASIS CSAF TC, `oasis-open/csaf-documentation` `static/icons/logo.svg` (LicenseRef-OASIS-CSAF-TC-License) |

The marks are trademarks of their owners. OpenVEX and the Transparency Exchange API have no published
logo, so they are set as text.
